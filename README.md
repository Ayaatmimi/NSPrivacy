# NSPrivacy

Public research artifacts for the NSPrivacy manuscript.

## Repository status

This repository preserves the values reported in the manuscript and provides a candidate implementation of the final DP-SGD and RDP-accounting pipeline. The implementation has not yet completed the full five-seed reproduction study. Reported tables must therefore be treated as manuscript artifacts, not as outputs regenerated by the current public pipeline.

## Contents

- `NSPrivacy/reported_results/`: reported manuscript results
- `NSPrivacy/dp_pipeline/`: candidate private-training implementation
- `NSPrivacy/notebooks/`: notebook release status
- `NSPrivacy/CODE_STATUS.md`: precise reproducibility status

No CIC-IDS2017 data, MIMIC-IV records, model checkpoints, credentials, or local paths are included.
